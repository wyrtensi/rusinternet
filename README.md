# RusInternet

Открытый статический сайт-помощник по безопасной установке официального набора российских доверенных сертификатов (НУЦ Минцифры) на Windows, macOS, Linux, iOS/iPadOS и Android.

Сайт помогает, когда браузер показывает ошибку сертификата («Ваше подключение не защищено», `ERR_CERT_AUTHORITY_INVALID`) на Госуслугах, в онлайн-банках и на маркетплейсах.

## Что внутри

- Автоопределение ОС и один понятный сценарий установки для каждой платформы.
- Пять заранее известных сертификатов (2 корневых + 3 промежуточных), публичный `manifest.json` и проверка **SHA-256** до любых системных изменений.
- Прозрачные установщики: `install-windows.cmd`, `install-macos.sh`, `install-linux.sh` и iOS-профиль — исходники открыты для проверки.
- Русская и английская главные, SEO-разметка (canonical, hreflang, JSON-LD `WebSite` + `FAQPage`), sitemap и `robots.txt`.

## Локальная разработка

```bash
npm ci
npm test        # 35+ проверок: платформы, сертификаты, установщики, manifest, workflow
npm run dev
```

Production-сборка:

```bash
npm run build   # astro check + astro build → dist/
```

## Публикация

Сайт разворачивается на **GitHub Pages** из ветки `main`: workflow `.github/workflows/deploy.yml` прогоняет тесты, собирает статику и публикует `dist/` на Pages. Собственный домен задаётся файлом `public/CNAME`; HTTPS выпускается автоматически (Let's Encrypt).

## Модель доверия

Установщики принимают только пять известных файлов и проверяют их SHA-256 перед изменением системного хранилища. Любое несовпадение останавливает установку. Сайт не обходит блокировки, не меняет DNS и не добавляет ГОСТ-шифрование в обычный браузер — он только устраняет ошибку доверия сертификату. Подробнее: [docs/SECURITY-NOTES.md](docs/SECURITY-NOTES.md).
